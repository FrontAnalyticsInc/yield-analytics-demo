# Yield Analytics Demo: surgical heart valves

End-to-end manufacturing yield analytics for a 50-step heart valve line (~100 valves a month).
It includes measurement SPC and five image-based quality inspections, and shows up in two places:

- **Power BI** for KPI reporting: first-pass yield, rolled throughput yield, step yield, Pareto, SPC, vision-model accuracy.
- **Deep-dive app** (FastAPI + React) for engineers: a root-cause explorer, SPC down to individual points, an inspection image gallery with defect overlays and AI-vs-inspector review, and the full device history for any serial number.

Everything except Power BI runs in one `docker compose` stack, on the homelab box *walden*,
published at **https://yield.frontanalytics.com**. The data is **synthetic**.

The docs also describe the production design for **thousands of valves a month and 20+ users**:
see [docs/architecture.md](docs/architecture.md).

## Quick start (local)

```bash
cp .env.example .env        # set DB_PASSWORD (8+ chars, upper/lower/digit/symbol) and EXPORT_KEY
docker compose up -d --build
open http://localhost:8000  # the first start backfills ~12 months (≈10 min, ~5,700 images)
```

| Service | Role |
|---|---|
| `db` | SQL Server 2022 (Developer), schema in `db/schema.sql` |
| `sim` | Deterministic production simulator plus synthetic inspection images; adds new production every 15 minutes |
| `api` | FastAPI: `/api/*` JSON, `/api/images/<id>.png`, `/exports/<table>.parquet?key=…` for Power BI, and the React app |
| `exporter` | Hourly Parquet star schema to `./exports` (and optionally Azure Blob) |
| `tunnel` | Cloudflare Tunnel (profile `tunnel`, walden only) |

Frontend development: `cd web && npm install && npm run dev` (proxies `/api` to `localhost:8000`).

## Demo stories built into the data

| Where to look | What you'll find |
|---|---|
| SPC → *Wireform diameter check* | Station **MS-15-2** drifts high from mid-May to early July 2026 (Cpk 0.87 vs 1.47 on MS-15-1) |
| Root-cause explorer → Tissue lot, area *Tissue* | Tissue lot **PT-2606-B** has elevated calcific-spot scrap |
| Root-cause explorer → Operator, area *Assembly* | New hire **OP-07** (swing shift, started March 2026) has a suture learning curve |
| Image inspections → *Only AI / inspector disagreements* | The vision model misses about a third of faint fibers/particulates, plus about 2% false positives |

## Experiments (design of experiments)

*Experiments → New experiment* sizes a two-level factorial for 1–3 factors (two by default), numeric or categorical:

- **Noise from the line:** σ comes from the response step's last 90 days; you enter the smallest change that matters.
- **Corner repeats:** calculated so the change is detected with 80% (Standard) or 90% (Strict) probability at 95% confidence, N ≈ 4σ²(z₁₋α/₂+z₁₋β)²/Δ².
- **Middle points:** set at the middle of the numeric factors only. There are 3 by default, fixed at the start, middle and end of the run order for curvature and drift checks, and split across values when a factor is categorical.
- **Diagram:** the design is drawn as a line, square or cube (one panel per categorical value), with a randomised run sheet. Save it with a name, objective, operator and notes.

Running (tagging units, confirming settings) and analysis come next.

A walkthrough is in [docs/demo-script.md](docs/demo-script.md).

## Deploy to walden

```bash
scripts/deploy-walden.sh    # rsync + docker compose --profile tunnel up -d --build
```

First time only, on walden in `~/src/yield-analytics-demo`: create `.env`, then create the tunnel and route:

```bash
sops exec-env ~/src/homelab/secrets/cloudflare.enc.env 'scripts/cf-tunnel.sh create walden-yield'
sops exec-env ~/src/homelab/secrets/cloudflare.enc.env 'scripts/cf-tunnel.sh route yield.frontanalytics.com http://api:8000'
```

## Power BI

See [docs/powerbi.md](docs/powerbi.md). The semantic model is TMDL in `powerbi/`, generated by
`powerbi/generate_model.py`. It refreshes from the Parquet feed with **no gateway**.
